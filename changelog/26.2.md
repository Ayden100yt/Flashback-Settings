## Flashback Settings 1.3.0 for Minecraft 26.2

### Fixed
- Game no longer crashes on startup if the config file is broken or hand-edited incorrectly – defaults are used instead
- Config is now saved safely, so it can't get corrupted if the game closes while saving
- Saving a replay no longer crashes if the replay folder path is invalid; it falls back to Flashback's default folder
- Paths with surrounding quotes (e.g. from Windows "Copy as path") now work everywhere, not only in the settings screen
- Replay counts on folders no longer freeze on symlinks/junctions, no longer show 0 when a subfolder can't be read, and now count .ZIP files too
- Fixed the settings screen drawing its background twice
- The keybind category now shows its proper name in the Controls menu
- Server names made only of dots can no longer create broken subfolders
- The settings screen no longer goes off-screen in very narrow windows
- The mod is now marked client-only, so it can't crash a dedicated server
